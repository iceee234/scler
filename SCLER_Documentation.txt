SCLER - SC Localization Enhancer Russian
========================================
Руководство пользователя
Документация от: 2026-08-12


1. Что делает программа
-----------------------

SCLER дополняет русский файл локализации игры Star Citizen полезной
информацией: чертежи, награды, типы модулей с классами, размеры оружия,
ресурсы майнинга, типы ракет и многое другое.

После её работы:
- В описаниях миссий появятся списки доступных чертежей с пометкой
  «Доступные чертежи».
- В названиях миссий появятся метки «[Чертежи]» или «[Чертежи]*».
- В описаниях появятся строки «Репутация за выполнение» и
  «Очки прогресса сценария» (опционально).
- Типы модулей в скобках будут переведены на русский язык с указанием
  класса (например, «Охладитель CIV-1A»).
- Название оружия будет дополнено размером (например, «Omnisky III Cannon (S1)»).
- Заголовки грузовых миссий будут упрощены и дополнены.
- Возможность добавления пользовательских заметок к миссиям.
- Возможность замены любых строк через пользовательский словарь.
- Названия ракет и торпед будут дополнены типом головки
  самонаведения (CS, EM, IR).
- Названия ресурсов майнинга будут дополнены значениями сигнатуры
  (например, «Bexalite (RS 3600)»).

После успешного завершения работы программы и добавления изменений
в файл локализации вы увидите на главной странице в игре слева
вверху надпись:
    Дополнено программой SCLER

Программу нужно запускать каждый раз после обновления файла global.ini,
который обычно выпускается командой локализации после каждого патча в игре.
При запуске программа проверяет наличие новых версий SCLER и устанавливает
обновления. Файл локализации и программы для его установки могут быть
скачаны из репозитория GitHub https://github.com/n1ghter/StarCitizenRu

Если вы запустите программу при запущенной игре, то изменения в игре
вы увидите только после её перезапуска.

Программа не вмешивается в другие данные игры и не изменяет ничего,
кроме указанных строк. При первом запуске создаётся резервная копия
исходного файла global.ini (с расширением .noblueprints.bak), чтобы
можно было всё вернуть обратно.

Программа распространяется под лицензией MIT. Исходный код
открыт и доступен для проверки, вредоносное содержимое отсутствует.

2. Что нужно для работы
------------------------

- Windows 10/11.
- PowerShell 5.1 или выше (встроен в систему).
- Права на запись в папку, где лежит программа.
- Права на запись в папку с файлом global.ini.
- Доступ к GitHub для скачивания файлов:
  https://github.com/MrKraken/StarStrings (contracts.ini, ordnance.ini, mining.ini)
  https://github.com/ssvasilev/STAR (STAR.bat)


3. Как запустить
-----------------

1) Скачайте последнюю версию SCLER с GitHub: https://github.com/iceee234/scler/releases
2) Распакуйте архив в удобное место.
3) Запустите SCLER.bat двойным щелчком мыши.
4) При первом запуске SCLER скачает STAR, который проведёт
   начальную настройку путей к игре и скачает файл локализации global.ini.
5) Дождитесь завершения обработки, нажмите любую клавишу.

Дополнительные ключи запуска:
  -?, -h, --help  Показать справку.
  -s, --skip      Применить только пользовательские заметки и словарь,
                  без повторной обработки всего файла.
  -p, --path      Выбрать файл global.ini через диалог и сохранить
                  путь в конфиг.
  -r, --restore   Восстановить global.ini из резервной копии
                  (global.ini.noblueprints.bak). Путь к файлу берётся
                  из конфига (GLOBAL_INI_PATH).
  -u, --update    Принудительная проверка обновлений SCLER.

Примеры:
  SCLER.bat
  SCLER.bat "D:\Games\RSI\StarCitizen\LIVE\data\Localization\korean_(south_korea)\global.ini"
  SCLER.bat -s

4. Как программа находит global.ini
------------------------------------
Программа ищет файл global.ini в следующем порядке:

1) Путь указан в аргументе командной строки.
2) Путь указан в SCLER.cfg.
3) Если настроена интеграция со STAR, программа запускает
   STAR.bat, который проверяет наличие обновлений локализации на GitHub
   и при необходимости скачивает актуальный global.ini.
4) Если файл не найден, программа предложит выбрать его через диалог.

5. Состав программы
--------------------

Файлы дистрибутива:
- SCLER.bat — основной запускаемый файл.
- scler.ps1 — основной скрипт обработки.
- scler_tables.ps1 — справочник программы.
- urls.cfg — служебный файл с адресами для загрузки данных.
- _updater.bat — служебный файл автообновления.
- user_notes.ini — пользовательские заметки к миссиям.
- user_dict.ini — пользовательский словарь замен.

Файлы, создаваемые при работе:
- SCLER.cfg — файл настроек.
- STAR.bat — скрипт установки локализации (скачивается автоматически).
- star_config.cfg — настройки STAR.
- update.zip, update_temp — временные файлы обновления.

Все файлы должны находиться в одной папке.

6. Дополнительные файлы
------------------------

Файлы contracts.ini, ordnance.ini и mining.ini скачиваются из репозитория
https://github.com/MrKraken/StarStrings при каждом запуске.
Они содержат информацию о чертежах, наградах, типах вооружений
и ресурсах для майнинга, добавляемых в описания миссий.

Файл STAR.bat скачивается из репозитория
https://github.com/ssvasilev/STAR при запуске программы, проверяет наличие обновлений
и скачивает файл русской локализации global.ini с GitHub.

Файл star_config.cfg создаётся STAR при начальной настройке
и содержит пути к игре и лаунчеру.

9. Пользовательские заметки
----------------------------

Файл user_notes.ini позволяет добавлять собственные заметки к описаниям
миссий. Заметки будут видны в игре в описании контракта.

**Внимание:** файл user_notes.ini должен быть в кодировке ANSI (Windows-1251),
иначе в игре вы получите нечитаемый текст.

Для использования:
1) Включите флаг USE_USER_NOTES=1 в SCLER.cfg.
2) Отредактируйте файл user_notes.ini, добавив строки в формате:
     ключ_миссии = текст заметки
3) Запустите программу повторно.

Как найти нужный ключ миссии:

1) Откройте файл global.ini в текстовом редакторе.
2) Найдите строку с текстом миссии, к которой хотите добавить заметку.
3) Скопируйте часть строки до символа "=" — это ключ миссии.
4) Вставьте ключ в файл user_notes.ini, после знака "=" напишите текст
   заметки (до 256 символов). Он будет добавлен в конец описания миссии
   после строки «Заметки».

Обратите внимание: в файле может быть несколько ключей с похожим
описанием. Убедитесь, что выбрали нужный ключ.

Пример заметки в файле user_notes.ini:
TheCollector_Intro_Desc=Рога тундровых копионов могут быть найдены в тундре,
например около Shubin Mining Facility SM0-13 или MT DataCenter KH3-AAE-L.


10. Пользовательский словарь замен
----------------------------------

Файл user_dict.ini позволяет заменять любые строки в global.ini
на собственные значения.

**ВНИМАНИЕ:** Необдуманная замена строк может привести
к неработоспособности игры. Делайте замены осторожно.
При нарушении работоспособности игры восстановите оригинальный
файл global.ini из резервной копии (global.ini.noblueprints.bak).

**Внимание:** файл user_dict.ini должен быть в кодировке ANSI (Windows-1251).

Для использования:
1) Включите флаг USE_USER_DICT=1 в SCLER.cfg.
2) Отредактируйте файл user_dict.ini, добавив строки в формате:
     ключ = значение
3) Запустите программу.

Для быстрого применения только пользовательских данных
без повторной обработки всего файла используйте ключ -s:
  SCLER.bat -s

Пример замены в файле user_dict.ini:
  Исходный текст в игре: RSI Perseus
  Добавленная строка замены в user_dict.ini:
    vehicle_NameRSI_Perseus=1.RSI Perseus
  Результат в игре: 1.RSI Perseus


11. Возможные проблемы
-----------------------

Проблемы установки:
- Error: PowerShell is required — PowerShell не найден.
  Установите или включите его в компонентах Windows.
- Error: scler.ps1 not found — файл отсутствует в папке с программой.
  Переустановите программу.
- Error: scler_tables.ps1 not found — справочник отсутствует.
  Переустановите программу.

Файл global.ini:
- Error: global.ini not found — файл не найден ни по одному источнику.
  Проверьте путь в SCLER.cfg (GLOBAL_INI_PATH) или запустите программу
  с ключом -p для выбора файла вручную.
- Error: Source file is too small — файл global.ini пуст или повреждён.
  Убедитесь, что интеграция со STAR включена (USE_STAR=1), и запустите
  программу повторно для скачивания актуального файла.
- Error: global.ini is not writable — нет прав на запись или файл
  используется другим процессом. Закройте игру, проверьте права.
- Error: Backup file not found — резервная копия не найдена при
  использовании ключа -r. Убедитесь, что в конфиге указан путь
  к global.ini (GLOBAL_INI_PATH) и бекап существует.

Интернет и загрузка:
- Ошибки «Failed to download contracts.ini / ordnance.ini / mining.ini» —
  нет интернета или сервер недоступен. Проверьте подключение и запустите
  программу повторно.
- Предупреждения «is empty» или «does not contain required marker» —
  скачанный файл данных (contracts, ordnance, mining) повреждён.
  Запустите программу повторно для скачивания заново.
- Проблемы со STAR.bat (не скачался, повреждён, не прошёл проверку) —
  интеграция со STAR отключена. Проверьте подключение к интернету,
  удалите STAR.bat (если есть) и запустите программу повторно.

Конфигурация:
- Warning: Could not create config file. Using default settings —
  не удалось создать файл настроек. Используются стандартные параметры.
- Warning: Value for COLOR_TAGS_X is too long. Using empty —
  слишком длинное значение цветового тега. Значение сброшено.
- Ошибки «URL_... not configured» — не настроены адреса для скачивания.
  Проверьте файл urls.cfg. При повреждении возьмите файл из дистрибутива.
- Warning: URL_STAR_API not configured — не настроен URL для проверки
  версий STAR. Используется текущая версия STAR без проверки обновлений.

Пользовательские данные:
- Warning: USE_USER_NOTES enabled but user_notes.ini not found —
  файл отсутствует. Отключение заметок.
- Warning: USE_USER_DICT enabled but user_dict.ini not found —
  файл отсутствует. Отключение словаря.
- Warning: note for '...' truncated to 256 characters —
  текст заметки превышает 256 символов и был обрезан.

Локализация:
- Warning: global.ini does not appear to be a Russian version.
  Программа предназначена для русского файла локализации. На английском
  файле некоторые маркеры будут переведены, но интерфейс останется
  английским.
- Warning: X ordnance keys not found in global.ini. The localization
  file may be outdated.
  ИЛИ
  Warning: X BP entries not found in global.ini. The localization
  file may be outdated.
  Файл локализации может быть устаревшим.

Ошибки записи:
- Error: Failed to create backup / write file —
  проверьте права доступа и свободное место на диске.

Обновление:
- !!! Previous update attempts failed. Update check skipped. !!! —
  обновление заблокировано после нескольких неудачных попыток.
  Запустите SCLER.bat -u для принудительной проверки обновлений.

Прочее:
- Error: PowerShell error occurred — внутренняя ошибка PowerShell.
- Ошибки «korean_ is not recognized» или «system cannot find the path»:
  возникают из-за скобок в пути к папке korean_(south_korea).
  Указывайте полный путь к global.ini в аргументе командной строки
  в двойных кавычках:
  SCLER.bat "D:\Games\RSI\StarCitizen\LIVE\data\Localization\korean_(south_korea)\global.ini"
