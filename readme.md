# SCLER - SC Localization Enhancer Russian

Улучшение русского файла локализации для Star Citizen. Добавляет информацию о чертежах, классах модулей, размерах оружия и многое другое в описания миссий.

## Возможности

- **Чертежи** — список доступных чертежей в описаниях миссий
- **Классы модулей** — (Охладитель CIV-1A), (Генератор щита MIL-2A)
- **Размеры оружия** — Omnisky III Cannon (S1)
- **Заголовки грузовых миссий** — направление, ранг, объём груза
- **Пользовательские заметки** — свои комментарии к миссиям
- **Словарь замен** — замена любых строк в игре
- **Резервное копирование** — автоматический бэкап global.ini
- **Интеграция со STAR** — автоматическое скачивание и обновление локализации

## Быстрый старт

1. Установить последний релиз русского файла локализации `global.ini`. Вы это можете сделать вручную, либо используя любые доступные инсталяторы [по ссылке](https://github.com/n1ghter/StarCitizenRu/).
2. Скачайте [последнюю версию SCLER](https://github.com/iceee234/scler/releases).
3. Распакуйте архив в любую папку.
4. Запустите `SCLER.bat`.
5. При первом запуске программа скачает STAR.bat, который автоматически найдёт или скачает актуальный `global.ini`.
6. Файл global.ini будет обновлён, и при следующем запуске игры вы увидите в ней обновлённую информацию.

## Состав дистрибутива

- `SCLER.bat` — запускаемый файл
- `scler.ps1` — основной скрипт обработки
- `scler_tables.ps1` — справочные таблицы
- `user_notes.ini` — пользовательские заметки (пример)
- `user_dict.ini` — пользовательский словарь замен (пример)
- `SCLER_Documentation.txt` — руководство пользователя

При первом запуске автоматически скачивается `STAR.bat` для интеграции с системой установки русской локализации.

## Ключи запуска

| Ключ | Описание |
|---|---|
| `-s`, `--skip` | Только пользовательские данные (заметки + словарь) |
| `-p`, `--path` | Выбрать global.ini через диалог |
| `-r`, `--restore` | Восстановить из бэкапа |
| `-?`, `-h`, `--help` | Справка |

## Требования

- Windows 10/11
- PowerShell 5.1+
- Доступ к GitHub для скачивания contracts.ini, ordnance.ini и STAR.bat
