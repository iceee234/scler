# SCLER - SC Localization Enhancer Russian

Улучшение русского файла локализации для Star Citizen. Добавляет в описания миссий информацию о чертежах, классах модулей, размерах оружия, ресурсах майнинга и многое другое.

## Возможности

- **Чертежи** — список доступных чертежей в описаниях миссий
- **Классы модулей** — (Охладитель CIV-1A), (Генератор щита MIL-2A)
- **Размеры оружия** — Omnisky III Cannon (S1)
- **Ресурсы майнинга** — Bexalite (RS 3600), Ice (Raw)
- **Заголовки грузовых миссий** — направление, ранг, объём груза
- **Пользовательские заметки** — свои комментарии к миссиям
- **Словарь замен** — замена любых строк в игре
- **Интеграция со STAR** — автоматическое скачивание и обновление локализации
- **Автообновление SCLER** — проверка новых версий и установка
- **Резервное копирование** — автоматический бэкап global.ini

## Быстрый старт

1. Скачайте [последнюю версию SCLER](https://github.com/iceee234/scler/releases).
2. Распакуйте архив в любую папку.
3. Запустите `SCLER.bat`.
4. При первом запуске STAR автоматически настроит пути к игре и скачает актуальный `global.ini`.
5. SCLER дополнит файл global.ini полезной информацией, и при следующем запуске игры вы увидите изменения.

## Состав дистрибутива

- `SCLER.bat` — запускаемый файл
- `scler.ps1` — основной скрипт обработки
- `scler_tables.ps1` — справочные таблицы
- `urls.cfg` — адреса для загрузки данных
- `user_notes.ini` — пользовательские заметки (пример)
- `user_dict.ini` — пользовательский словарь замен (пример)
- `SCLER_Documentation.txt` — руководство пользователя

| Ключ | Описание |
|---|---|
| `-?`, `-h`, `--help` | Справка |
| `-p`, `--path` | Выбрать global.ini через диалог |
| `-r`, `--restore` | Восстановить global.ini из бэкапа |
| `-s`, `--skip` | Обработка только пользовательских данных (заметки + словарь) |
| `-u`, `--update` | Принудительная проверка обновлений |

## Требования

- Windows 10/11
- PowerShell 5.1+
- Доступ к GitHub для скачивания contracts.ini, ordnance.ini, mining.ini и STAR.bat
